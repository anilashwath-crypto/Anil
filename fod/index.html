Camera

The snapshot URL must return a JPEG and allow cross-origin access (CORS). Most DVR/IP cameras expose one (e.g. /snapshot.jpg, /cgi-bin/snapshot.cgi). If blocked, serve this page from the same gateway or use a USB capture dongle on the CCTV's analogue/HDMI output.

Door-lock relay

Works with any relay that accepts an HTTP call: Shelly, Tasmota/Sonoff, ESP8266/ESP32 sketch. Wire the relay to the door solenoid lock. Leave blank to use the on-screen indicator only.

⚠️ Safety: FOD Guard is a process-assist check, not a certified safety device. The door interlock must still go through a proper safety relay / guard switch as per your machine's safety standard. Never bypass it with this system alone.
